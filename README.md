# RzSMTH-Android

水木社区 BBS 第三方 Android 客户端，基于 [zfdang/zSMTH-Android](https://github.com/zfdang/zSMTH-Android) 修改的个人使用版本，显示名为 **RzSMTH**。

## 相对上游的改动

1. 登录流程改为桌面版页面，移除腾讯验证码
2. 修复登录后仍显示「点击登录」
3. 修正图片 CDN 域名
4. 附件图片强制走主站
5. 调整字体档位
6. 新增「屏蔽设置」
7. 应用改名
8. 主界面改为底部四栏导航
9. 新增「我的」页面
10. 版面主题排序方式
11. 图片分享
12. 信息流

## 版本更新

完整的版本变更记录见 [ChangeLog.md](ChangeLog.md)。
