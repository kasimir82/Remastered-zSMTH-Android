# RzSMTH-Android

水木社区 BBS 第三方 Android 客户端，基于 [zfdang/zSMTH-Android](https://github.com/zfdang/zSMTH-Android) 修改的个人使用版本，显示名为 **RzSMTH**。

## 主要对 zsmth 老版的改动

- **a0** 加入用户黑名单和帖子标题关键字黑名单
- **a0** 复制帖子文本加入大爆炸选择（点选词条后复制）
- **a** 更改登录方式，使用 index.html，没有人机确认
- **a** 全自动翻页：每次点击下半屏幕自动拉取帖子并对齐（致敬十几年前的特快水木 App）
- **b** 原程序图片引用链接有误，已修正
- **c** 新增按回帖时间排序和发文时间排序（不确定能用）
- **d** 界面大改，底部导航栏改为 4 按钮潮流样式
- **e** 增加信息流界面：鉴于本站版面死的差不多了，可勾选收藏夹内几个版面在同一页浏览
- **g** 图片加入分享功能
